# ActiveAppTime

ActiveAppTime показывает, сколько времени за сегодня вы провели в текущем приложении. Время отображается в постоянном уведомлении, а если устройство поддерживает Android Live Updates и система разрешает их показ — ещё и в чипе рядом с часами.

## Установка и запуск

1. Скачайте `app-debug.apk` из последнего [релиза на GitHub](https://github.com/marbar0407/ActiveAppTimeOpencode/releases/latest) и установите его. Android может попросить разрешить установку из источника, из которого вы открыли APK.
2. Откройте ActiveAppTime и нажмите **Разрешить доступ к использованию**. В системных настройках выберите ActiveAppTime и выдайте доступ.
3. Нажмите **Разрешить уведомления**, чтобы видеть время. Если на устройстве доступны Live Updates, проверьте их в разделе **Настройки Live Updates (чип)**.
4. Нажмите **Запустить мониторинг**. Если система регулярно останавливает мониторинг в фоне, можно попробовать отключить оптимизацию батареи для ActiveAppTime через одноимённую кнопку.

Для установки нужен **Android 12 или новее**. Приложение запрашивает показ чипа начиная с API 36, но его появление зависит от устройства и системных настроек. Если чип недоступен, время можно смотреть в панели уведомлений.

## Как считается время

- При запуске приложение читает системную историю использования с местной полуночи, поэтому учитывает и время до запуска мониторинга.
- Данные проверяются каждые 5 секунд. Когда экран выключается или блокируется, открытые сессии закрываются.
- На домашнем экране, в системном интерфейсе и в самом ActiveAppTime уведомление сохраняет время последнего отслеживаемого приложения.
- Если мониторинг был включён, ActiveAppTime пытается запустить его снова после перезагрузки устройства.

Приложение обрабатывает статистику на устройстве и не запрашивает доступ к интернету.

## Сборка из исходников

Проект состоит из одного Android-модуля `app` на Kotlin с XML-разметкой. Для сборки нужны **JDK 17**, **Gradle 8.13** и **Android SDK Platform 36**. Gradle Wrapper в репозитории нет, поэтому установите Gradle отдельно.

Из корня проекта выполните:

```sh
gradle assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

[GitHub Actions](.github/workflows/build.yml) собирает debug APK при обновлении ветки `main` и публикует его в разделе Releases.
